# Exploring London's Travel Network

This project explores London's public transport journey data using SQL and Snowflake.

## Project Overview

The goal is to analyze journey volumes across different transport types, identify popular travel periods for Emirates Airline, and find the years with the lowest Underground & DLR usage.

## Questions Explored

- Which transport types have the highest number of journeys?
- Which months and years were the most popular for Emirates Airline?
- Which years had the lowest Underground & DLR journey volumes?

## Skills Used

- SQL
- Aggregate functions (`SUM`)
- Filtering (`WHERE`)
- Grouping (`GROUP BY`)
- Sorting (`ORDER BY`)
- Limiting results (`LIMIT`)
- Rounding values (`ROUND`)

## Tools

- Snowflake
- DataCamp
